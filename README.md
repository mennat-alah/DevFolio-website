# DevFolio – Personal Portfolio Website

A responsive personal portfolio website built with **HTML5, CSS3, and Bootstrap** as part of my frontend development practice.

The project focuses on recreating a modern portfolio layout while practicing responsive design, Bootstrap components, CSS animations, transitions, and interactive UI elements.

## Features

- Responsive navigation bar with a mobile menu
- Full-screen hero section with an animated typing effect
- About section with skill progress bars
- Resume section with an education and experience timeline
- Services section with hover effects
- Portfolio gallery with category tabs
- Statistics and achievements section
- Testimonials carousel
- FAQ accordion
- Contact section and footer
- Responsive layouts for different screen sizes

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- Google Fonts

## What I Practiced

- Building responsive layouts using Bootstrap's grid system
- Using utility classes for spacing, alignment, and typography
- Creating animations with CSS `@keyframes`
- Applying hover effects and transitions
- Positioning elements with Flexbox and CSS positioning
- Customizing Bootstrap components
- Organizing styles with CSS variables
- Improving the layout across different screen sizes
